# Objection Handling

## “Why not just use several separate wallets?”
Using separate wallets can work, especially for users who prefer ecosystem-specific tools. Dompet-Ku is intended for users who value a more unified way to view supported assets and review wallet actions across multiple ecosystems.

## “Is self-custody too risky?”
Self-custody gives the user control, but it also creates responsibility. Dompet-Ku can help with clearer review flows and warnings; users still need to protect recovery information and verify every action.

## “Can you guarantee this dApp or transaction is safe?”
No. We can help explain visible details and warning signs, but no wallet or assistant can guarantee that a dApp, contract, or transaction is risk-free.

## “Will a bridge always be cheap and fast?”
No. Cost and completion time depend on the selected route, network conditions, liquidity, and other factors. Users should review the quote and total cost before confirming.

## “Can the AI tell me exactly what to buy?”
The assistant can help users understand information and risks, but it should not provide personalized investment instructions or guarantee outcomes.

## “Why do I need to approve a token?”
Some decentralized services need permission to interact with a token. Users should review who is requesting it, why it is needed, and the allowance amount before approving.
