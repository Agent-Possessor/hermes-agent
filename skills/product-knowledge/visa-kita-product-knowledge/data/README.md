# Data Tables

These CSV files are the numeric working set for Visa Kita product knowledge.
Use them before making any pricing, margin, package, or competitor conclusion.

- `products.csv`: product scope, family, purpose, and approved-internal list prices
- `active-pricing.csv`: current package proposals and offer status
- `unit-costs.csv`: government fees, levy, payment fee, customer service, and operations costs
- `benefits.csv`: inclusions, add-ons, and evidence status
- `competitors.csv`: observed competitor offers and source IDs
- `assumptions.csv`: model assumptions that still need validation

If a question is numeric, start here, then cross-check the narrative docs in `pricing/` and `references/`.
